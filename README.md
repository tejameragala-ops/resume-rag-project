# Resume RAG Project

## Overview
This project is an AI-powered Resume Analyzer built using Retrieval-Augmented Generation (RAG).

## Features
- Upload resume PDF
- Extract text from resume
- Match skills with job requirements
- AI-based resume analysis
- ATS-friendly feedback

## Tech Stack
- Python
- Streamlit
- OpenAI API
- LangChain
- FAISS

## Project Workflow
1. User uploads resume
2. Resume text is extracted
3. Text is converted into embeddings
4. Vector database stores embeddings
5. User asks questions
6. AI retrieves relevant data and generates answers

## Run Locally

Install dependencies:
pip install -r requirements.txt

Run project:
streamlit run app.py
